# 校园集市（校园轻集市）—— Vue 实训项目规划

## 一、页面清单

| 序号 | 页面名称 | 路由路径 | 页面说明 | 主要功能点 |
|------|----------|----------|----------|------------|
| 1 | 首页 | `/` | 应用入口，商品推荐与分类导航 | 轮播图Banner、分类快捷入口、推荐商品列表、搜索入口 |
| 2 | 用户登录 | `/login` | 账号密码/验证码登录 | 表单校验、记住密码、第三方登录占位 |

| 4 | 商品列表 | `/products` | 商品浏览与筛选 | 分类切换、排序（价格/时间/销量）、关键词搜索、分页加载 |
| 5 | 商品详情 | `/product/:id` | 商品完整信息展示 | 图片轮播、价格/描述展示、联系卖家、加入购物车、收藏 |
| 6 | 发布商品 | `/product/create` | 卖家发布新商品 | 多图上传、分类选择、标题/描述/价格输入、预览 |
| 7 | 编辑商品 | `/product/:id/edit` | 卖家编辑已有商品 | 回显已有信息、重新提交 |
| 8 | 购物车 | `/cart` | 购物车商品管理 | 商品列表、数量增减、选中/全选、结算跳转 |
| 9 | 确认订单 | `/order/confirm` | 下单确认页 | 收货地址选择/新增、商品清单、总价计算 |
| 10 | 订单列表 | `/orders` | 用户所有订单 | 选项卡切换（全部/待付款/待发货/待收货/已完成） |
| 11 | 订单详情 | `/order/:id` | 单笔订单详情 | 物流信息、商品清单、操作按钮（付款/取消/确认收货） |

| 17 | 消息通知 | `/messages` | 系统消息与互动通知 | 消息列表、已读/未读标记 |

## 二、功能模块

### 2.1 用户模块

| 子功能 | 说明 | 涉及页面 |

## 四、开发重点

### 4.1 Vue 3 核心语法

| 重点 | 说明 | 示例场景 |
|------|------|----------|
| `<script setup>` 组合式 API | 全部页面和组件使用 `setup` 语法 | 所有 `.vue` 文件 |
| `ref()` / `reactive()` | 响应式数据声明 | 表单数据、列表数据 |
| `computed()` | 计算属性，依赖追踪 | 购物车总价、筛选后的商品列表 |
| `watch()` / `watchEffect()` | 侦听器，副作用处理 | 搜索防抖、路由参数变化 |
| `provide()` / `inject()` | 跨层级数据传递 | 全局用户信息透传 |
| 生命周期钩子 | `onMounted`、`onUnmounted` 等 | 数据初始化、定时器清理 |

### 4.2 Vue Router 重点

| 重点 | 说明 | 应用位置 |
|------|------|----------|
| 嵌套路由 | 个人中心下的子路由（我的发布/收藏/设置） | `router/index.ts` |
| 路由懒加载 | `() => import('@/views/...')` 按需加载 | 所有非首页路由 |
| 动态路由匹配 | `:id` 参数传递 | 商品详情、订单详情 |
| 导航守卫 | `router.beforeEach` Token 校验 | 全局鉴权 |
| 编程式导航 | `router.push` / `router.replace` | 登录后跳转、操作后跳转 |

### 4.3 Pinia 状态管理

| 重点 | 说明 | 应用位置 |
|------|------|----------|
| Store 模块化 | 按业务拆分为独立 Store | `stores/user.ts`、`stores/cart.ts` 等 |
| Actions 异步处理 | 登录请求、商品获取等异步逻辑 | 所有 Store |
| Getters 派生状态 | 基于 state 计算派生数据 | 购物车数量、订单统计 |
| `storeToRefs` | 保持解构后的响应性 | 组件中使用 Store 时 |
| 持久化插件 | `pinia-plugin-persistedstate` 缓存购物车/Token | `main.ts` |

### 4.4 组件化开发

| 重点 | 说明 | 示例组件 |
|------|------|----------|
| 父子组件通信 | `defineProps` + `defineEmits` | 商品卡片 -> 列表页 |
| 插槽（Slots） | 灵活布局 | 布局组件、弹窗组件 |
| 通用组件封装 | 复用 > 重复 | `GoodsCard.vue`、`TabBar.vue`、`Loading.vue`、`Empty.vue` |
| 递归组件 | 分类树形结构（如需） | 二级分类菜单 |

### 4.5 前后端交互

| 重点 | 说明 | 实现方式 |
|------|------|----------|
| Axios 封装 | 实例化、请求/响应拦截器 | `api/request.ts` |
| Token 注入 | 请求拦截器从 Store 读取 Token 添加到 Header | `api/request.ts` |
| 统一错误处理 | 响应拦截器处理 401/500 等状态码 | `api/request.ts` |
| API 模块化 | 按业务拆分接口函数 | `api/user.ts`、`api/product.ts`、`api/order.ts` |
| 请求/响应类型定义 | TypeScript 接口约束 | `types/api.ts` |

### 4.6 TypeScript 实践

| 重点 | 说明 | 应用场景 |
|------|------|----------|
| 接口定义 | `interface` 定义数据结构 | 商品、订单、用户等所有数据模型 |
| 泛型 | 封装通用请求函数 | Axios 返回类型 |
| 类型推导 | 利用 Vue 3 的类型推导 | `defineProps`、`ref` 自动推导 |
| `tsconfig` 严格模式 | 已启用严格模式，遵循类型约束 | 全局 |

### 4.7 常见坑点与建议

| 问题 | 建议 |
|------|------|
| 响应式丢失 | 始终使用 `ref`/`reactive` 包裹响应式数据，不要直接解构 Store |
| 异步更新尚未完成 | `watch` 或 `nextTick` 处理 DOM 更新后的操作 |
| 路由参数变化不刷新 | 使用 `watch` 监听 `$route.params` 重新获取数据 |
| 图片上传预览 | 使用 `URL.createObjectURL` 生成临时预览地址 |
| 组件命名冲突 | 遵循 PascalCase 命名，多词组合避免与 HTML 标签冲突 |
| CSS 作用域 | 使用 `<style scoped>` 避免样式污染 |
| 列表 key | `v-for` 务必绑定唯一 `key`，优先使用 `id` |
| 表单校验 | 封装校验规则，统一错误提示样式 |
| 内存泄漏 | 组件卸载时清除定时器、事件监听 |
